# CompareThemesWithR

**Веб-приложение для оценки изменений в корпусе новостных сообщений** — R + Shiny.

Загружаете выгрузки постов региональных сообществ за разные периоды — приложение извлекает ключевые слова и фразы, показывает их динамику во времени и строит **тренд-карты** («динамика / значимость»), чтобы видеть, какие темы набирают популярность, какие теряют, а какие остаются стабильно значимыми.

Проект выполнен в рамках бакалаврской работы (СГУ им. Н.Г. Чернышевского, направление «Информатика и вычислительная техника», 2025).

> **In short (EN):** an R/Shiny app for tracking how topics in regional news corpora change over time. It extracts keywords with TF / TF-IDF / RAKE on lemmatised Russian text (UDPipe), compares up to 6 time periods, builds cosine-similarity matrices and “dynamics vs. significance” trend maps. Tested on regional VK news data for 2020–2024.

---

## Задача

Региональные новостные сообщества публикуют тысячи постов в год. Нужно быстро понять, **о чём пишут и как это меняется**: какие темы только появились, какие стали обсуждать активнее, какие ушли.

Особенности задачи, которые определили решения в проекте:

- **данные не размечены** (посты собраны из региональных сообществ VK), поэтому методы машинного обучения с учителем неприменимы — используются методы извлечения ключевых слов и фраз;
- **русский язык** с богатой морфологией — перед подсчётом нужна лемматизация и фильтрация шума (ссылки, эмодзи, имена, служебные слова);
- нужна **сравнимая оценка** тем между периодами, а не просто список частотных слов.

## Возможности

- Загрузка данных по периодам из файлов `.xlsx` (до **6 периодов**, по одной вкладке на период).
- Выбор метода извлечения ключевых слов: **TF** или **RAKE**.
- Для каждого периода:
  - облако слов (`wordcloud2`);
  - столбчатая диаграмма топ-10 ключевых слов;
  - таблица топ-10;
  - выгрузка результатов вычислений в файл.
- Вкладка **«Оценка динамики»**:
  - сравнение всех проанализированных периодов;
  - **матрица косинусного сходства** между периодами;
  - **тренд-карта** с осями «динамика» и «значимость»;
  - выгрузка результатов сравнения.

## Как это работает

```
 .xlsx с постами  →  очистка текста  →  лемматизация (UDPipe)  →  извлечение ключевых слов (TF / RAKE)
                                                                          │
        тренд-карта  ←  динамика и значимость  ←  сравнение периодов (косинусное сходство)
```

### 1. Предобработка
- приведение к UTF-8 и нижнему регистру, удаление цифр;
- удаление ссылок, эмодзи и служебных символов (регулярные выражения);
- лемматизация и морфологическая разметка русского текста моделью UDPipe `russian-gsd` (используется параллельная обработка);
- фильтрация стоп-слов: стандартный список русского языка + расширенный список, собранный по региональным корпусам + словари мужских/женских имён и фамилий (`*_names_rus.txt`, `male_surnames_rus.txt`);
- нормализация типичных искажений лемм и слитно написанных хэштегов.

### 2. Извлечение ключевых слов
- **TF** — частота термина относительно общего числа слов в периоде.
- **RAKE** — ключевые фразы до 3 слов, составленные только из существительных и прилагательных; минимальная частота фразы настраивается в коде. Реализация RAKE адаптирована под задачу (собственная версия `keywords_rake` с дополнительной фильтрацией фраз).

### 3. Оценка динамики и значимости тем
Готовой методики в источниках, на которые я ориентировался (тренд-карты в стиле iFORA), найти не удалось, поэтому показатели определены самостоятельно:

- **значимость** фразы — сумма её оценки (TF / RAKE) по всем анализируемым периодам;
- **динамика** фразы — средний абсолютный прирост значимости между первым и последним периодами.

На тренд-карте по этим двум осям видно, какие темы растут, какие падают и какие стабильно значимы.

## Запуск

**Требования:** R ≥ 4.0, RStudio (рекомендуется), доступ в интернет при первом запуске.

1. Склонируйте репозиторий и откройте `Result_with_UI_6tabs.R` в RStudio.
2. Установите рабочую директорию в папку проекта — оттуда читаются словари имён и фамилий:
   ```r
   setwd("путь/к/CompareThemesWithR")
   ```
3. Запустите скрипт (**Run App** в RStudio). При первом запуске автоматически:
   - устанавливаются и подключаются необходимые пакеты (`shiny`, `tm`, `udpipe`, `dplyr`, `tidyverse`, `tidytext`, `data.table`, `ggplot2`, `ggrepel`, `wordcloud`, `wordcloud2`, `lsa`, `readxl`, `writexl`, `openxlsx`, `rlang`);
   - скачивается модель UDPipe `russian-gsd-ud-2.5-191206`.
4. Загрузите файлы по периодам, нажмите «Вывод результатов», затем перейдите на вкладку «Оценка динамики».

> Если приложение не стартовало автоматически, выполните в консоли `shiny::runApp()` из папки проекта либо `shinyApp(ui, server)`.

### Формат входных данных
`.xlsx`-файл: тексты постов в одном столбце, без строки заголовка. **Исходные данные в репозиторий не включены.**

## Ограничения и планы

- Расширенный список стоп-слов настроен под конкретные региональные корпуса (названия регионов, имена руководителей и т.п.); для других данных его нужно пересмотреть.
- Всё приложение находится в одном скрипте — следующий шаг: разделить на модули (интерфейс, предобработка, методы, визуализация) и добавить тесты.
- Количество периодов фиксировано (6 вкладок).
- Идеи развития: контейнеризация (Docker), настройка параметров (число слов, минимальная частота фразы) из интерфейса, сравнение с тематическим моделированием (LDA).
